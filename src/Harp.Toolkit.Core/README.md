## About

`Harp.Toolkit.Core` provides common toolkit infrastructure to inspect, update and interface with [Harp devices](https://harp-tech.org).

## How to Use

The `Harp.Toolkit` command-line tool installs this package as a dependency. To use that tool, refer to the [Harp Toolkit documentation](https://harp-tech.org/toolkit).

This package is internal to the Harp toolkit and to the graphical tools that use it. Its public API changes when those tools change. Breaking changes are frequent. Each one goes into a new major version, so reference an exact version of this package. For a stable Harp client API, use [`Bonsai.Harp`](https://harp-tech.org/api/Bonsai.Harp.html) instead.

## Additional Documentation

For additional documentation and examples, refer to the [official Harp documentation](https://harp-tech.org).
